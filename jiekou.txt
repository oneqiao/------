表关系图
text
sys_user（用户）          agent（代理）           merchant（商户）
     │                        │                        │
     │                        │                        │
     │                 独立使用                   agent_id ──→ agent.id
     │                        │                        │
     │                        │                        │
     └── 权限控制              └────── 1对多 ────────┘       │
                                                            │
                                                      1对多  │
                                                            ↓
                                                  merchant_card（商户卡号）
关系说明：

merchant.agent_id → agent.id（多对一：一个代理可管理多个商户）

merchant_card.merchant_id → merchant.id（多对一：一个商户可拥有多张卡片）

sys_user 独立，用于系统登录和权限管理

二、接口设计
通用响应格式
json
{
  "code": 200,
  "message": "success",
  "data": null,
  "timestamp": 1702656000000
}
code值	说明
200	成功
400	参数错误
401	未登录
403	无权限
404	资源不存在
500	服务器错误
1. 用户模块
功能	方法	路径	说明
用户登录	POST	/api/auth/login	登录认证，返回token
获取当前用户	GET	/api/auth/current	获取登录用户信息
用户登出	POST	/api/auth/logout	退出登录
用户列表	GET	/api/users	分页查询用户
添加用户	POST	/api/users	新增用户
编辑用户	PUT	/api/users/{id}	修改用户信息
删除用户	DELETE	/api/users/{id}	删除用户
1.1 用户登录
text
POST /api/auth/login
请求体：

json
{
  "username": "admin",
  "password": "123456"
}
响应：

json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIs...",
    "userInfo": {
      "id": 1,
      "username": "admin",
      "firstName": "系统",
      "lastName": "管理员",
      "email": "admin@example.com",
      "isAdmin": true,
      "isEnabled": true
    }
  }
}
1.2 用户列表
text
GET /api/users?page=1&size=10
请求参数：

参数	类型	必填	说明
page	int	否	页码，默认1
size	int	否	每页条数，默认10
keyword	string	否	关键词（模糊匹配用户名/姓名/邮箱）
isEnabled	int	否	是否启用（0禁用，1启用）
isAdmin	int	否	是否管理员（0否，1是）
startTime	string	否	创建开始时间
endTime	string	否	创建结束时间
响应：

json
{
  "code": 200,
  "message": "success",
  "data": {
    "total": 100,
    "page": 1,
    "size": 10,
    "list": [
      {
        "id": 1,
        "username": "admin",
        "firstName": "系统",
        "lastName": "管理员",
        "email": "admin@example.com",
        "isEnabled": true,
        "isAdmin": true,
        "createTime": "2026-01-01 10:00:00",
        "lastLoginTime": "2026-04-15 09:30:00"
      }
    ]
  }
}

json
{
  "merchantNo": "M10002",
  "name": "B商户",
  "merchantType": "white",

3.4 编辑商户
text
PUT /api/merchants/{id}
请求体：

json
{
  "name": "B商户-新名称",
  "merchantType": "refund",
  "agentId": 2,
  "accountStatus": 1,
  "fundFreeze": 0
}
注：merchantNo、loginAccount 不可修改

3.5 删除商户
text
DELETE /api/merchants/{id}
逻辑： 将 account_status 改为 2（删除状态）

响应：

json
{
  "code": 200,
  "message": "删除成功"
}
3.6 调整余额
text
POST /api/merchants/{id}/balance
请求体：

json
{
  "type": "recharge",
  "amount": 1000.00,
  "reason": "客户充值"
}
type值	说明
recharge	充值（增加余额）
withdraw	提现（减少余额）
响应：

json
{
  "code": 200,
  "message": "调整成功",
  "data": {
    "oldBalance": 5000.00,
    "newBalance": 6000.00,
    "changeAmount": 1000.00
  }
}
3.7 导出商户列表
text
GET /api/merchants/export
请求参数： 同“商户列表”的查询参数

响应： Excel文件

text
Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet

导出字段： 商户号、商户名称、商户类型、代理名称、登录账号、账号状态、资金冻结、当前余额、开卡数、卡内余额、创建时间

四、状态码说明
账号状态（account_status）
值	说明
0	禁用
1	正常
2	删除（软删除）
资金冻结（fund_freeze）
值	说明
0	未冻结
1	冻结
商户类型（merchant_type）
值	说明
white	白量
refund	退款
用户启用状态（is_enabled）
值	说明
0	禁用
1	启用
代理状态（status）
值	说明
0	禁用
1	启用
卡状态（card_status）
值	说明
0	禁用
1	正常
