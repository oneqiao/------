一、表关系说明

sys_user（用户）          agent（代理）             merchant（商户）
    独立使用                 独立使用                  agent_id -> agent.id
                                                        |
                                                        | 一对多
                                                        v
                                               merchant_card（商户卡）

关系说明：

1. merchant.agent_id -> agent.id
   一个代理可以管理多个商户。

2. merchant_card.merchant_id -> merchant.id
   一个商户可以拥有多张卡。

3. sys_user 独立存在
   用于后台登录和权限管理。

二、通用响应格式

```json
{
  "code": 200,
  "message": "success",
  "data": null,
  "timestamp": 1702656000000
}
```

状态码说明：

| code | 说明 |
| --- | --- |
| 200 | 成功 |
| 400 | 参数错误 |
| 401 | 未登录 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 500 | 服务器错误 |

3. 新增商户

```text
POST /api/merchants
```

请求体：

```json
{
  "merchantNo": "M10002",
  "name": "B商户",
  "merchantType": "WHITE",
  "agentId": 1,
  "loginAccount": "merchant02",
  "loginPassword": "123456",
  "accountStatus": 1,
  "fundFreeze": false
}
```

说明：

1. `merchantType` 使用枚举字符串，按代码实现存储为 `WHITE` 或 `REFUND`。
2. `currentBalance`、`cardCount`、`cardBalance` 由系统初始化，新增接口不接收这三个字段。

4. 编辑商户

```text
PUT /api/merchants/{id}
```

请求体：

```json
{
  "name": "B商户-新名称",
  "merchantType": "REFUND",
  "loginAccount": "merchant02_new",
  "accountStatus": 1,
  "fundFreeze": true
}
```

说明：

1. 当前代码允许修改 `name`、`merchantType`、`loginAccount`、`accountStatus`、`fundFreeze`。
2. 已删除商户不允许再编辑。

5. 删除商户

```text
DELETE /api/merchants/{id}
```

逻辑说明：

1. 删除为软删除。
2. 代码会把 `account_status` 更新为 `2`。
3. 已删除商户默认不会出现在列表和导出结果中。

6. 调整余额

```text
POST /api/merchants/{id}/balance
```

请求体：

```json
{
  "type": "recharge",
  "amount": 1000.00,
  "reason": "客户充值"
}
```

`type` 说明：

| 值 | 说明 |
| --- | --- |
| recharge | 充值，增加余额 |
| withdraw | 提现，减少余额 |

响应示例：

```json
{
  "code": 200,
  "message": "调整成功",
  "data": {
    "oldBalance": 5000.00,
    "newBalance": 6000.00,
    "changeAmount": 1000.00,
    "reason": "客户充值"
  }
}
```

说明：

1. 已删除商户不允许调整余额。
2. 冻结商户不允许调整余额。
3. 金额必须大于 0。

7. 导出商户

```text
GET /api/merchants/export
```

请求参数与商户列表一致。

响应：

```text
Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet
Content-Disposition: attachment; filename=merchants_<timestamp>.xlsx
```

导出字段：

1. 商户号
2. 商户名称
3. 商户类型
4. 代理ID
5. 账号状态

六、状态值说明

1. 商户账号状态 `account_status`

| 值 | 说明 |
| --- | --- |
| 0 | 禁用 |
| 1 | 正常 |
| 2 | 删除（软删除） |

2. 资金冻结 `fund_freeze`

| 值 | 说明 |
| --- | --- |
| 0 | 未冻结 |
| 1 | 冻结 |

3. 商户类型 `merchant_type`

| 值 | 说明 |
| --- | --- |
| WHITE | 白量 |
| REFUND | 退款 |

4. 用户启用状态 `is_enabled`

| 值 | 说明 |
| --- | --- |
| 0 | 禁用 |
| 1 | 启用 |

5. 代理状态 `status`

| 值 | 说明 |
| --- | --- |
| 0 | 禁用 |
| 1 | 启用 |

6. 卡状态 `card_status`

| 值 | 说明 |
| --- | --- |
| 0 | 禁用 |
| 1 | 正常 |
